# Policy Debt Register

Status: Project-owned register template
Authority: docs/policies/repository-engineering-policy.md

No measured findings are inherited from another repository. Absence of a
finding does not establish compliance. Record confirmed pre-existing findings
with ID, path, revision/date, governing rule, reproducible evidence, risk,
owner, permitted next action and required verification. Keep unmade planning
or tooling decisions separate from measured failures. Close findings only
with fix evidence or explicit human exception and follow-up.
